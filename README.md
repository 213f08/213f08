### 🚀 Featured Projects

- **[buy-check](https://github.com/213f08/buy-check)** — a pre-purchase due-diligence tool for second-hand gear: pick a category, set a budget, mark what matters, and it returns five check cards (positioning, model matrix, market prices, pitfalls and inspection checklist, trade-offs). Every price claim carries its source and fetch time — it does not recommend, it assembles the facts you need to decide.
- **[fox-ai-agent](https://github.com/213f08/fox-ai-agent)** — a Spring AI "agent toolbox": each app is a separate capability slot (diet-and-health chat, RAG retrieval, tool calling, service reports) built as hands-on practice rather than a demo.
- **[hmall-springcloud](https://github.com/213f08/hmall-springcloud)** — splitting a monolithic e-commerce backend into item / cart / user / pay / trade services plus a gateway, with Nacos for discovery and OpenFeign for service-to-service calls.
